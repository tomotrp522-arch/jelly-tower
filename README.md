# ぷるぷるゼリータワー

スマートフォンでゼリーを左右にドラッグし、指を離してお皿に積み上げる2Dバランスゲームです。Matter.js の重力・衝突・摩擦・回転と、Canvas の変形アニメーションを組み合わせています。iPhone / Android の縦画面とPCに対応します。

## 開発

Node.js 24 と npm を使用します。

```sh
npm ci
npm run dev
```

表示される開発サーバーをブラウザで開きます。PCではゲーム領域をクリックしてから左右キーで移動、スペースキーで落下できます。タッチ・マウスでも操作できます。ゼリーがお皿の下まで落ちるとゲームオーバーです。最高スコアと効果音設定は端末の localStorage に保存します。プライベートモード等で保存できなくてもプレイ可能です。音楽と効果音は最初のタップ・キー操作後に有効になります。右上の音符ボタンで両方をまとめて切り替えられ、従来と同じ `jelly-sound` に設定を保存します。

```sh
npm run build
npm run preview
```

`dist/` が公開対象です。APIキー・バックエンド・外部フォント・実行時CDNは不要です。依存ライブラリはビルドに含まれます。

## 自動テスト

```sh
npm ci
npx playwright install --with-deps chromium
npm run build
npm test
```

システムの Chromium を使う場合は `CHROMIUM_PATH=/usr/bin/chromium npm test`。テストは Chromium の iPhone / Android / PC 設定で `/jelly-tower/` 配下を開き、タッチによる2個の積み上げ、落下とゲームオーバー、リトライ、ベスト記録保存、効果音設定保存、キーボード操作、オフライン再読み込み後のプレイを確認します。

## GitHub Pages で公開

1. GitHub の `tomotrp522-arch/jelly-tower` を開き、**Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
2. `main` に push すると `.github/workflows/pages.yml` がビルド・ブラウザテスト・公開を実行します。設定を切り替えた後、必要なら **Actions → Test and deploy GitHub Pages → Run workflow** を実行してください。
3. Actions の deploy が成功したら、`https://tomotrp522-arch.github.io/jelly-tower/` で遊べます。無料の GitHub Pages が利用できるリポジトリ／プランで使用してください。

Vite の `base: './'`、manifest と Service Worker の相対URLにより、サブディレクトリでも動作します。公開URLの確定は Pages のデプロイ結果で確認してください。

## ホーム画面・オフライン

- iPhone: Safari で公開URLを開き、共有メニュー → **ホーム画面に追加**。
- Android: Chrome のメニュー → **ホーム画面に追加** または **アプリをインストール**。
- 初回はオンラインで開き、Service Worker のアセット保存完了後にオフラインで遊べます。HTTPS（開発時は localhost）が必要です。端末のキャッシュ削除後は再取得が必要です。
- 更新時にキャッシュ対象を変更した場合は `public/sw.js` の `VERSION` を更新してください。更新版のインストール後、開いているゲームをすべて閉じて再度開くと切り替わります。

## 構成

- `src.js`: 入力・Matter.js・カメラ・ゲームイベント・スコア保存
- `audio.js`: オリジナルBGM・効果音のWeb Audio生成、先読みスケジューラー
- `motion.js`: 剛体と独立した変形・接触グラフ上の時間差振動
- `art.js`: 6色の立体ゼリー・ランダム表情・スイーツショップ背景・フリル皿のCanvas描画
- `style.css` / `index.html`: 雲のスコア表示・パステルUI・レスポンシブレイアウト
- `public/`: PWA manifest・Service Worker・アイコン
- `tests/`: Playwright の実ブラウザテスト

柔らかさは剛体物理に重ねた視覚表現です。物理モデルそのものはソフトボディではありません。ブラウザの実機ごとの差は iPhone / Android でも確認してください。

## デザインと演出

ピンクのカーテンと水色の空を背景に、白いフリル皿にゼリーを積みます。6色のゼリーにはランダムな4種類の表情・ほっぺ・白いハイライトを描き、着地すると星とハートが飛び散ります。背景のイチゴ・リボン・花を含め、すべてローカルの Canvas 描画と CSS で構成し、参照画像を背景に貼り付けていません。背景は起動時に一度描画して再利用します。

「視差効果を減らす」等の reduced-motion 設定では、装飾パーティクル・ゼリーの描画上の揺れ・スコア拡大を抑えます。ゲームの物理演算と操作は変わりません。画面幅320〜1280pxで横方向のはみ出しとボタンの配置を自動確認します。ブラウザの端末エミュレーションでの検証であり、iOS Safari / Android Chrome の実機確認を置き換えるものではありません。

## ぷるぷるの動き

落下速度に応じた縦伸びに、着地直後の横つぶれ・縦の反動・約4〜5周期の減衰振動を重ねます。接触しているゼリーへ42msずつ遅れて振動が伝わり、高い位置ほど左右の揺れが少し増えます。体の上部と下部は時間差をつけて変形し、顔とハイライトも同じ変形に追従します。揺れている間はほっぺが赤くなります。

変形はキャッシュした高解像度の描画素材にのみ適用します。重力・摩擦・反発・剛体の大きさ・当たり判定・カメラ・スコア条件は変更しません。透過素材の境界に横線が出ないよう、変形を別Canvasの整数ピクセル行へ描画してから回転・拡大します。端末の reduced-motion 設定ではこれらの変形を抑制します。

## オリジナル音楽「Sugar Window」

110 BPM、ハ長調、4/4拍子・16小節（約34.9秒）のオリジナル曲です。マリンバ・オルゴール／ベル・柔らかなピアノを、サイン波の倍音と音量エンベロープで合成します。128個の8分音符ステップをWeb Audioの時間基準で180ms先まで予約し、ループ境界でも既存の余韻を切りません。映像フレームレートに音のタイミングを依存させていません。

離す音・着地音・大きな揺れの音・3/5/10個（以降10個ごと）のチャイム・最高記録更新のファンファーレ・ゲームオーバー音を生成します。最高記録のファンファーレは1プレイで1回に抑え、大きな揺れの音にも1.5秒のクールダウンがあります。BGMは控えめな音量とし、ゲームオーバー時に滑らかに下げ、リトライ時に戻します。音の重なりにはコンプレッサーを使用します。

音は初回のユーザー操作後に開始します。タブが非表示になると再生を一時停止し、復帰時は過去の音符をまとめて鳴らさず再開します。端末側で音声再開が拒否された場合は次のタップで再開を試みます。音声機能が使えない環境でもゲームは継続します。外部音源・外部API・音楽配信サービスは利用せず、初回キャッシュ後は音楽もオフラインで再生します。

テストは単体7件（変形の減衰・振動伝播・物理計算への非干渉・楽曲ループ・スケジューリング・効果音の間引き）と、iPhone / Android / PC設定のブラウザテストを実行します。実際のWeb Audioグラフで初回操作・ミュート・効果音・ゲームオーバー時のフェード・リトライを確認し、OfflineAudioContextで2周分の波形を生成してループ境界の無音・クリッピング・急激な波形変化を検査します。オフラインでの音声再生も確認します。音楽の最終的な聴感と音量は端末・スピーカーでもご確認ください。
